Fundamentos Matemáticos (Graph Data Science)

O motor de inteligência modela a rede como um grafo direcionado ponderado \( G = (V, E, W) \), utilizando medidas centrais para mensurar a criticidade estrutural:

# PageRank de Privilégio Estrutural:
PR(u) = (1 - d)/N + d * Σ (PR(v) / OutDegree(v))

# Centralidade de Intermediação (Chokepoint Detection):
C_B(v) = Σ (σ_st(v) / σ_st) [para todos s ≠ v ≠ t]

# Menor Caminho de Ataque de Menor Fricção (Dijkstra):
AttackCost(Path) = Σ W(e_i) + Σ ΔPrivilege(u, v)

CREATE TABLE graph_metrics (
  node_id TEXT PRIMARY KEY REFERENCES network_nodes(id),
  pagerank_authority REAL NOT NULL,
  betweenness_chokepoint REAL NOT NULL,
  blast_radius_nodes INTEGER NOT NULL,
  blast_criticality INTEGER NOT NULL
);
